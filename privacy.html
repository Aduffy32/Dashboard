Privacy Policy

Last updated: May 2026

This app is a personal tool built for private use and is not available to the public.

Data collected

  • Google account email address (for authentication)
  • Health and fitness data manually entered (weight, water intake, workouts, supplements)
  • Whoop data synced via the Whoop API with explicit user permission

How data is stored

All data is stored in a private Supabase database accessible only to the account owner. No data is sold or shared with third parties.

Third-party services

  • Supabase — database and authentication
  • Google — OAuth sign-in
  • Whoop — fitness data via API
